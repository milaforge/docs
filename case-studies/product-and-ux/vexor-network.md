# Vexor Network

### **Problem**

During pre-beta onboarding, failures could appear as generic errors. A user would know that something went wrong but not what to do next.

### **What I did**

I replaced generic errors with application-level messages that explained the problem and provided a clearer recovery path. I also reduced unnecessary API calls through client-side caching, improving the perceived speed of the application.

### **Outcome**

Users got clearer feedback when something failed, while common interactions required fewer unnecessary requests.
