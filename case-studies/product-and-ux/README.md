# Product & UX

These cases show how I approach product problems from the user's side: identify where the workflow is difficult, reduce unnecessary steps, and build only what helps the user reach the intended outcome. The focus is on practical product decisions rather than visual design.

This section is to answer the following question:

> "Can I turn a product requirement or user problem into a useful, maintainable system?"
