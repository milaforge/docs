# MCI

At MCI, part of the problem was not a single vulnerability. Security work involved repetitive checks, manual steps, and finding vulnerabilities late in development.

I looked for ways an attacker could benefit from that delay:

> If a vulnerability is introduced today but discovered weeks later, how much harder is it to fix?

I automated repetitive security checks and worked with development teams to find and fix vulnerabilities before production. I also converted security requirements into practical tools and guidelines.

### **Outcome**

The security work saved about three hours per day and moved vulnerability detection earlier in the development process, reducing both manual work and the chance of human error.
