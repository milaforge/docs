# Bugdasht

_BugDasht_ is a cybersecurity platform where users could submit security reports and receive bounty payments. That meant users could not simply be treated as trusted application users.

I had to consider questions such as:

* Can a user access another user's information?
* Can a report or payment flow be manipulated?
* Can actions be traced later if something is disputed?
* What information needs to be recorded to satisfy security and regulatory requirements?

I built auditability and reporting into the product and worked with the founder and early users to turn security requirements into actual workflows.

### **Outcome**

Security controls became part of the product itself, rather than a separate set of rules that users and developers had to work around.
