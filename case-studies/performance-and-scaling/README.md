# Performance & Scaling

I work on performance when slow or expensive software starts limiting the product: users cannot be served at the required volume, requests take too long, or infrastructure costs grow faster than usage.

This section answers the question:

> "Can I make a growing system handle more load without simply throwing more infrastructure at it?"
