# Software Releases

### VENT Finance

Releases relied too much on manual checking and deployment steps. This made it easier for mistakes to reach production.

I introduced automated tests and a deployment process that checked changes before releasing them.

### **Outcome**

Reduced manual release work and the risk of deployment errors.

***

### Vexor Network

Before the beta launch, deployments needed to become more predictable. Manual release steps can turn a small mistake into a production problem.

I improved the deployment process and added automated tests, while separating development, staging, and production environments.

### **Outcome**

deployments became more consistent, with fewer deployment mistakes and a faster release cycle.
