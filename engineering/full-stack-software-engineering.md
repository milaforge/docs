# Full-Stack

> Full-stack software engineering covering application development, architecture, production systems, code review, performance, and legacy modernization.

I build and evolve software across the stack—from user-facing applications and APIs to databases, infrastructure, and production systems.

I am comfortable joining an existing codebase, building something new, or taking software through the difficult transition from `it works` to `it works reliably for real users`.

### What I work on

#### 1. Building software

Applications, APIs, backend systems, frontend applications, integrations, and the infrastructure needed to run them.

#### 2. Understanding existing systems

Reading unfamiliar codebases, tracing how systems actually work, identifying technical constraints, and finding the changes that matter.

#### 3. Improving software

Performance, reliability, maintainability, testing, observability, and code quality.

#### 4. Taking software into production

Deployment, operational concerns, failure handling, monitoring, and the practical problems that appear when software meets real users.

#### 5. Evolving older systems

Modernizing legacy applications without throwing away useful business knowledge embedded in the existing system.
